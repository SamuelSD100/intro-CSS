# introdução ao CSS
 neste repositorio, abordamos os principais conceitos necessarios para começar a estilizar paginas **HTML** e compreender como o navegador interpreta e aplica regras de estilo.

## o que é o CSS?
**CSS(cascading style Sheets)** é a liguagem utilizada para definir a apresentação visual dos elemnetos *HTML*

## formas de aplicar o CSS
- CSS Inline
- CSS Interno
- CSS Externo
