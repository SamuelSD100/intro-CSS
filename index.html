O que é o CSS?

o CSS significa cascading Style Sheets, ou Folhas de estilo em cascata

Sobre o CSS

Linguagem responsavel por definir a aparencia visual e organização dos elementos na tela.

Como aplicar o CSS?

Para o CSS, temos tres abordagens

  • CSS inline
  • CSS interno
  • CSS externo

O que da pra fazer com o CSS

o CSS não serve apenas para colocar cor na pagina. Ele controla:

  • cores
  • fontes
  • tamanhos
  • espaçamentos
  • sombras
  • bordas
  • posicionamentos
  • responsividade
  • animações
  • transições

Aplicando o CSS inline

Nessa abordagem, o CSS é colocando diretamente no elemento HTML através do trabalho do atributo style

Aplicando o CSS interno

Nessa abordagem, o CSS é abordado dentro de uma < style > dentro do < head > do documento HTML.

Aplicando o CSS externo

Nessa abordagem, os estilos de CSS ficam concentrados em um arquivos separados.

Para conectar esse arquivo ao HTML, utilizamos o elemento <link >
